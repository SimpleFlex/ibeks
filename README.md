# PRIMO

Next.js (App Router) build of the PRIMO Figma design: Home, Creamly case study, Field notes, About, dark/light toggle, responsive.

    npm install
    npm run dev      # http://localhost:3000
    npm run build && npm start

Colors live in `app/globals.css` (CSS variables; Ember accent). Replace `hello@example.com` in `app/about/page.jsx`.
